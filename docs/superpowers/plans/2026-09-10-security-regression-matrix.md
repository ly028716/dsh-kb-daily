# 安全回归矩阵实现计划

## 目标

补齐路径安全与诊断输入边界的回归覆盖，重点验证 Windows junction、相对/绝对 symlink、TOCTOU、超大报告、异常编码和权限不足场景，并确保失败原因仍以安全摘要形式向上层暴露。

## 实施任务

1. 扩展路径和文件系统测试矩阵：覆盖文件与目录 symlink 的相对/绝对目标、Windows junction 的读/写/存在性链路、超大报告、异常 UTF-8 和权限错误。
2. 增加确定性的 TOCTOU 回归测试，在路径检查完成后替换目标，验证读写不会跟随被替换的链接或覆盖链接目标。
3. 修复安全路径解析，使既有检查与实际读写之间再次验证物理路径 containment；保持现有错误分类和报告大小限制。
4. 执行聚焦测试、类型检查、构建、打包检查和 diff 检查，记录剩余的平台差异。

## 验证标准

- 测试在当前平台通过；Windows 专属 junction 用例在 Windows 上真实执行，其他平台明确跳过。
- 相对和绝对 symlink 均不能被读取、写入或作为报告目录使用。
- TOCTOU 替换发生时操作失败，外部目标内容不被读取或修改。
- 超过 512 KiB 的报告、异常编码和权限不足均产生可断言的结果，不泄露文件内容。
